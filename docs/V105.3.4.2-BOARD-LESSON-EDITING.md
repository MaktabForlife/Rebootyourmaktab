# V105.3.4.2 — Board lesson editing and multiple tabs

Development branch: `feature/v105.3.4-timetable`. This revision continues the manual assisted planner from V105.3.4.1.

## Use

1. Choose a class and subject or module, then select an empty period. Teacher assignment is optional and can be added later.
2. Select any displayed lesson to edit its subject, classes, teacher, times or lesson Zoom link. **Move to another period** selects the lesson for placement in an empty cell. **Delete this day** removes the selected weekday. Undo reverses the last board change.
3. Editing, moving or deleting one weekday of a recurring lesson leaves its other weekdays intact. All lessons in an occupied cell are shown separately, so each can be selected.
4. Use **Open this board in a new tab** after selecting a class or teacher. Tabs for the same Program and signed-in account share draft changes. A change to the same item in two tabs stops saving and displays a conflict notice so one edit is not silently discarded. Concurrent saves from different tabs retry after merging independent lesson changes.
5. Save the draft, validate, preview and publish as before. The live timetable changes only after publication.

## Boundaries

Teacher boards show assigned lessons; lessons without a teacher appear on their class boards. New board tabs reuse the same Program draft. Cross-Program teacher commitments are still outside the planner's checks. The 100-row and draft storage limits still apply.

## Verification

Planner tests cover unassigned teachers, board editing, moving, deleting, recurring weekdays and undo. The full backend test suite and Worker build are run for this revision. This revision has not been deployed.

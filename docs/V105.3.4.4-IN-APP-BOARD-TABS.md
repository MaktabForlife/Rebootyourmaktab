# V105.3.4.4 — Timetable boards in one screen

Development branch: `feature/v105.3.4-timetable`.

## Use

The **New board tab** button sits above the weekly grid. It opens a class board that is not already open, or an unused teacher board after the class boards have been opened. Choose another class or teacher in that tab's controls whenever needed. Select a tab to return to its board; each tab remembers its class or teacher and default subject. Close a tab with ×. The original board remains until another is opened.

All tabs show the same timetable draft. A lesson placed in one tab appears in other relevant boards when they are selected. The existing conflict checks apply across all boards. Save the draft to store lessons, breaks, periods and teacher availability. The tab strip itself is a screen arrangement and is rebuilt when the page is reloaded.

Switching tabs closes an open lesson or break editor with no changes. If it contains unsaved changes, the switch is stopped until those changes are saved or closed. Keyboard users can select tabs with Left/Right Arrow, Home and End.

## Verification

Planner tests cover opening, switching and closing in-page class and teacher board tabs, including remembered choices and a lesson and undo reflected across tabs. Full regression tests and a Worker dry build verify this revision. This revision has not been deployed.

# V105.3.4.3 — Direct timetable board editing

Development branch: `feature/v105.3.4-timetable`. This revision continues the manual assisted planner from V105.3.4.2.

## Use

1. Enter the initial number of periods, first start time and usual duration. After setup, those controls are hidden. Each board row shows editable start and end times. Use **Add period** to append another row; use the row's × to remove one that has no lessons or breaks.
2. Enter a time such as `745`, `7:45` or `07h45`. The board displays it as `07h45` after the change. Periods must stay in time order without overlapping. Existing lesson and break times remain fixed; the board prevents an edit that would make one disappear from its row.
3. Select **Mark break**, enter a name such as Lunch, then select an empty day and period. The break applies to every class and appears on class and teacher boards. Select the break card to edit its label or times, move it, or delete only that weekday. Matching breaks on several weekdays can share one row in the draft.
4. Select an empty board cell to choose its subject or module and optional teacher, then select **Add**. The toolbar choices are defaults. Use the pencil icon on an existing lesson to change those choices in its card, or use **More details** for classes, times and the lesson link.
5. Drag a lesson to an empty period to move its selected weekday. Use the delete icon to clear that weekday's lesson after confirming; the period row and any occurrences on other weekdays remain. **Undo last board change** restores the previous board state.
6. For teacher availability, tick several days or use **Mon–Fri**, then enter one available time range. Times accept `745` and display as `07h45`. An overlap on any selected day stops the whole addition so no partial range is saved.
7. The board prevents a break from overlapping a lesson or another break. Save the draft to store the plan; preview and publish remain separate.

## Boundaries

Periods are a shared planning grid for the Program. They do not change the actual times of existing lessons or breaks. Breaks are Program-wide and cannot be used as class-specific free periods. The existing 16-period and 40-break-row limits apply. Cross-Program clash checks remain outside this planner.

## Verification

Planner tests cover inline period editing, three-digit time normalization, overlap rejection, adding and removing periods, break placement and overlap checks, inline lesson choices, drag movement, confirmed selected-weekday deletion, cancellation, multi-day teacher availability, atomic overlap rejection and undo. This revision has not been deployed.

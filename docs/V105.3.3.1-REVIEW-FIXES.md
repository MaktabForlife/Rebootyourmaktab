# V105.3.3.1 — Review corrections

Development targets: `feature/v105.2-program-timetable`, `maktab-development` and `devrebootworker`. No main/live changes or direct academy spreadsheet edits are part of this release.

## User profiles and meeting links

The eye action opens **View login link** in a dialog, using the same existing personal URL as Share and Copy. The toolbar contains Save all and, while editing a column policy, Save access setting. Individual users are saved through their row icon; typing a name makes that icon available without leaving the input. Free/Paid changes retain their separate confirmation and save.

Classes and the timetable builder display the complete clickable Zoom URL. Preview/PDF meeting links still use the module or subject name. Single-class fallback and the combined-class shared-link requirement are unchanged.

## Chronological preview and exports

All lesson and break boundaries form a common time axis. A 07h45–09h15 lesson spans the 07h45–08h30 and 08h30–09h15 rows when another day has two shorter lessons. Matching shared entries, such as Assembly, merge horizontally with one centred label by default. Entries with different curriculum identities, teachers, classes, links, times or cancellation state remain separate. Adjacent distinct lessons are not combined into a double session. When separately defined rules share a merged cell, the edit actions identify the relevant day.

Empty intervals remain visible and are not silently labelled Break. HTML, PNG and PDF use the same cell-span model and layout preferences. Long schedules paginate with repeated headings; spanning cells continue on another page when a clean boundary cannot fit. Unreasonably tall content produces an explicit export error rather than clipped text. PDF titles remain clickable; image files have no interactive links and PDF visual text remains rasterized.

## Breaks and layout editing

**＋ Break** creates a timetable entry with a label, weekdays and start/end times. It applies to every class in the program, requires no subject/module/teacher/Zoom URL, and remains visible when filtering by class. Validation rejects overlaps with lessons or other breaks. A maximum of 40 break rows is accepted. Existing subjects named Break are neither converted nor deleted automatically.

**Adjust layout** exposes relative column widths, minimum row heights, left/centre/right alignment, and a switch for merging matching entries across days. Cells expose Edit lesson/Edit break, and an empty interval offers Add break. The entry dialog applies to the draft and requests a fresh preview and validation. Text can expand the minimum row height. Layout-only adjustments remain local until Save draft or Publish; they require no spreadsheet write per input.

Breaks and layout are additive fields in the existing bounded weekly draft and immutable publication JSON. No Sheets schema or identity migration is needed. Cached weekly editors preserve fields they omit. Older dated editors are prevented from overwriting a saved break/layout draft. Edit as new version copies both fields; published history is read-only. Teachers remain optional, and effective dates remain publication-only.

# V105.3.3.3 — Compact Blocks

Development-only update on `feature/v105.2-program-timetable`, `maktab-development` and `devrebootworker`.

The Blocks time axis now marks each 30 minutes and starts from a 60px-per-half-hour scale rather than 120px. Bounds round out to half-hours, while lessons retain their exact minute positions, proportional heights and real gaps. Text can increase the shared scale only where needed to avoid overlap.

Short entries (up to 20 minutes) use the available horizontal space for the linked title, start/end times, teacher and classes. These fields wrap when necessary; no information is removed. Ordinary blocks use tighter line spacing and padding. All seven weekdays can be exported together, removing the earlier forced split after five days. The reference morning timetable now exports as one page instead of two.

The original Table renderer and stylesheet remain untouched. No timetable records, saved layouts or published snapshots are changed. The worker change only updates release metadata.

Verification: regression tests cover 30-minute labels, proportional positions and gaps, text bounds, all short-entry fields, one-page morning and seven-day exports, and continued pagination for unusually dense schedules. Real canvas/PDF output was checked visually and for clickable title annotations. The reference morning PDF has one page and six linked titles; uneven-time and seven-day samples also fit one page. A dense 15-hour example still paginates to keep its content legible. This is compact layout, not unlimited shrinking of text to force every possible schedule onto a single sheet.

User acceptance with the current academy schedule and device download/share behaviour remains open.

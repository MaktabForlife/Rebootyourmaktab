# V105.3.3.4 — Class and teacher timetables

Development-only update on `feature/v105.2-program-timetable`, `maktab-development` and `devrebootworker`.

The block timetable is now the only preview and export layout. The Table selector, all-classes view and table layout controls have been removed from the user interface. A preview must show one class or one assigned teacher, and the PNG/PDF filenames identify that selection.

Class timetables show the selected class in the heading and the assigned teacher inside each lesson block. Teacher timetables show the selected teacher in the heading and the class or combined classes inside each lesson block. The heading is `UMM ABBAD ACADEMY` followed by `[name] Weekly timetable`. Draft or published version information, effective date and timezone remain in the footnote.

Breaks remain visible across class timetables. A teacher timetable includes a break only on a day when that teacher has a lesson. Break blocks do not display class or teacher labels. Module titles retain clickable links in PDF output.

No timetable draft, publication or spreadsheet schema changes are required. Existing publications are rendered through the new audience selection when viewed.

Verification covers class and teacher filtering, omission of repeated names, headings and footnotes, break handling, no-write audience changes, export bounds, PDF links and one-page reference schedules. Real class and teacher PDFs were rendered and inspected. Full regression and development deployment checks are recorded with the release.

User acceptance of real timetable selections, downloads and sharing remains open.

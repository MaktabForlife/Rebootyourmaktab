# V105.3.1.4 — Class module completion

Each class/module pair has an explicit progress status: Active (studying), Inactive (not currently studying), or Completed (finished). A class without a saved status shows Not recorded. Completing a module for one class does not complete it for another class, archive the reusable module, cancel lessons, change learner access, or rewrite published history.

## Use

In Overview, click the status beside a class name, select Active, Inactive or Completed, and Save. Use the row's Class status action to record another class, or open Module progress to add/edit records. The same controls work in desktop rows and mobile cards. Existing records can be changed back from Completed to Active or Inactive.

Module availability remains Active/Archived and is labelled Availability in the module editor. Class status is separate because combined classes can finish the same module at different times. Classes with recorded progress remain visible in the overview even when their lessons are later removed from the saved draft. Teachers and learner counts still derive from the draft and dated class memberships.

## Persistence and validation

ProgramModuleProgress is stored inside the existing ProgramManagementState snapshot, with ProgressID, CourseID, ProgramModuleID, ClassID and Status. Old snapshots are upgraded in memory with an empty collection; no spreadsheet preparation or new sheet tab is required. A unique module/class pair is enforced. Saved pairs cannot be reassigned; edit their status instead. Both references must belong to the Program. Active requires an active module and class; historical completion can be recorded for archived references.

The existing admin authority, draft-Program guard, revision checks, durable intent, atomic snapshot/receipt and idempotent retry protections apply. Each saved snapshot retains author/time metadata and prior snapshots remain available. General curriculum edits preserve progress records. This is a class-level completion marker, not individual learner assessment. No automated cancellation or scheduling restriction is introduced by completion.

# V105.3.3.2 — Optional timetable blocks

Development targets: `feature/v105.2-program-timetable`, `maktab-development`, `devrebootworker`.

## Use and rollback

In Publication preview or Published history, select **View → Blocks (trial)**. Table remains the initial default. The selection is kept for this program in the browser tab's session. Selecting **Table** immediately restores the original table and its draft layout controls. The original table renderer and stylesheet are unchanged; V105.3.3.1 is also preserved in commit `c612ea8`.

Changing views does not save, modify, or republish a timetable, and requires no Google Sheets requests. Existing schedules, table preferences, publication snapshots, and the weekly storage format are unchanged. Lesson editing continues in the builder. This trial adds a display option, not drag-and-drop scheduling.

## Display and export

Rounded blocks contain start/end times, the module or subject name and meeting link, teacher when assigned, and classes. A single proportional time axis positions blocks at exact minutes, including uneven times such as 08h10. Gaps remain visible. Overlapping classes receive separate lanes. Matching entries can span adjacent displayed days only when times, content, curriculum identity, teacher, classes, URL and cancellation state match. Existing merge preferences are respected. Standalone breaks remain visible in class filters.

PNG and PDF use the selected view. PDF module titles remain clickable. Images have no interactive links. Exports group up to five days and paginate long time ranges with repeated headings; continued blocks keep their details. Short entries expand the shared time scale sufficiently to fit their text. Very dense content may need a class filter or Table view for export. Table width/height/alignment controls apply to Table only.

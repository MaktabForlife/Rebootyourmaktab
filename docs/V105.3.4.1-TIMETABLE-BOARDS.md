# V105.3.4.1 — Timetable boards and time-range availability

Development branch: `feature/v105.3.4-timetable`. Staff place lessons manually. The planner presents weekly class and teacher boards generated from the same period setup; it does not assign lessons automatically.

## Use

1. Set the number of periods, first start time and usual duration. The weekly board appears as a day-by-period table. Individual period start and end times can then be adjusted for gaps and different lengths.
2. Choose **Class** or **Teacher** under “Show timetable for.” The class and teacher selections identify the timetable being viewed. Choose a class, subject or module, and teacher to add a lesson by selecting an empty cell. An occupied cell can be selected and moved to another day and period; Undo reverses the last board placement or move.
3. For each teacher, add one or more available **day, from time, to time** ranges. Once a teacher has a range, every lesson must fit inside a single range on its weekday. A teacher with no ranges has no availability restriction. An optional weekly teaching-hour limit remains available.
4. Save the draft, validate, preview and publish through the existing effective-date workflow. The detailed lesson editor still supports combined classes, Zoom links and times outside the period grid.

The former weekly teaching requirements and “Place requirement” control have been removed. Older saved requirement rows and period-status availability rows are discarded when a draft is normalised into this revision. Lesson rows are retained.

## Time and validation

Program setup and new timetable drafts use `Africa/Johannesburg` (South Africa Standard Time, UTC+02:00) without a timezone selector. New publications use that timezone; historical published snapshots retain their original timezone.

The server checks period time ranges and overlaps, teacher availability ranges, weekly teacher-hour limits, break overlaps, and existing teacher, class, Zoom and learner conflicts. Planner settings remain private to the draft and are not included in published timetable snapshots.

## Current boundaries

The board works within one Program. Cross-Program teacher commitments remain outside its checks. Period times are common across weekdays. Drafts support at most 100 lesson rows and the existing 40,000-character storage limit.

## Verification

Tests cover 15 teachers with time ranges, class and teacher board rendering, direct placement, unavailable times, weekly hour limits, moves and undo, draft persistence and publication validation. This revision has not been deployed.

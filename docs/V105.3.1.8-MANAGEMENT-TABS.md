# V105.3.1.8 — Consolidated management tabs

## Authorized scope

Implemented after the user explicitly resumed work following the V105.3.1.6 testing pause. Earlier acceptance remains open. Target only `feature/v105.2-program-timetable`, the `maktab-development` Pages project and `devrebootworker`. No changes to `main`, the live site, credentials, program roles or real curriculum records.

## Navigation and curriculum

The five visible tabs are Overview, Modules, Subjects, Classes and User profiles, without item counts. Subjects and levels in Overview remain collapsed initially; opening either immediately displays module rows. The aligned Subject / Levels / Modules summaries are retained.

Modules has a Level (optional) selector: No level, Beginner, Intermediate, Advanced. Saving a module creates or reuses its subject's standard level in the same management snapshot and recovery receipt. Replayed writes reuse the exact committed level identity. An acknowledgement includes the related level so its name stays visible even if the next read hits a quota limit. Existing custom level links remain visible and may be kept on their current module; only an explicit selection replaces them. Their records and published history are not deleted or renamed. Standard levels with existing inactive records are reactivated when selected for an active module. New modules do not introduce custom level choices.

Levels is no longer a separate tab. Unused level records do not block archiving their parent subject once its modules are archived; the level records stay intact and their effective availability still depends on the subject. Active modules continue to block subject archival.

## Class progress

The Modules grid includes one Class progress column. Each recorded class status is an edit action; Add class status opens an inline class/status editor in the same module row. Statuses are Active, Inactive and Completed. Each class/module pair is unique, and an existing progress record cannot be moved to a different class or module. Completing one class does not archive the module, change another class's status or alter timetable lessons. The overview's status actions open this same inline editor.

Drafts and save recovery continue using their original record kind, comparison revision and operation identity even when their public tab is Modules or User profiles. Earlier Level and Teacher drafts remain finishable/cancellable without exposing those tabs. Browsing, quota cooldown, safe retries and explicit same-field conflict review remain intact.

## User profiles and teachers

User profiles displays the existing academy account directory with account status, all active roles in this program, and class memberships. Its Class memberships action opens the existing dated enrollment editor scoped to that account. It supports additions and edits while preventing accidentally selecting a different user within that view. Membership alone does not grant a program role. Profile creation/editing and role grants across programs are deferred to V105.3.2.

The Teachers tab is removed. Timetable candidates are active accounts with an active Teacher, Senior or Admin grant in the selected program. A role in another program or platform administration alone does not qualify. Legacy ProgramTeachers assignment flags no longer override those roles; historical records remain stored. Revoking the role or deactivating the account removes timetable eligibility. No access grants are changed by this patch.

Editing help

Edit names and status directly in the sheet. Select a Program or Course role cell to change Student, Teacher and Program Admin roles. Save all or Ctrl/⌘ + Enter saves your changes.

Global Admin applies to every Program and Course. Role cells edit additional scoped roles; they cannot remove Academy-wide authority. Existing Course subscribers appear as Students. None means no assigned role or Course subscription; access to a Free Course is separate.

Inactive keeps the account and its roles. Course Student changes also update the existing Course access control. Module media subscriptions are separate and are not available yet.
